# Supplied artwork

Six original SVG creature illustrations and three SVG habitat backgrounds were created for this teaching package. Students may use and adapt these assets in their MTM6302 coursework and publish that coursework on GitHub Pages. No external image services, fonts, or third-party asset libraries are used. Keep this note with redistributed starter files.

Creature files: moss-dragon.svg, cloud-fox.svg, ember-salamander.svg, moon-owl.svg, crystal-turtle.svg, mushroom-sprite.svg.
Habitat files: habitat-forest.svg, habitat-sky.svg, habitat-desert.svg.
